# proje adı:kod_asistanim
## Projenin Amacı
Kullanıcılara günlük işlerinde (hesaplama,selamlama)
## Projenin Hedefleri
* v1.0 Akıllı Menü: **Kullanıcıya dinamik
* v2.0 Veri Saklama
* v3.0 Sesli Komut

## Kritik Eşik Mantığı
1.Başla
2.Kullanıcıdan yaş bilgilerini al(yas)
3.Eğer yas>=18 ise:
  3.1 "Erişim izni verildi" yazdır
  Değilse:
  3.2 "Erişim engellendi: Yaş sınırı" yazdır.
4.Bitir.
